EQ for macOS › No driver

A Mac equalizer without BlackHole or a virtual driver

macOS does not include a general-purpose system-wide equalizer, which is why many Mac equalizers ask you to install a virtual audio device. Since macOS 14.2 there is another way, and EQ uses it.

Updated 21 November 2026 · Applies to EQ 0.6.0

The usual way, and why it is awkward

An app cannot normally intercept the sound other apps send to your speakers. The long-standing workaround is a virtual audio device, a loopback driver such as BlackHole. You make that virtual device your system output, the equalizer app reads what arrives there, processes it and plays it on your real speakers or headphones. It works, but you install a driver, your output and volume keys now point at the virtual device, and removing it later is a chore.

The process tap way

macOS 14.2 added a Core Audio API called a process tap, which lets an app read the audio that other processes play. EQ builds on it:

  1. It creates a tap of what plays on your output device, except its own sound, mixed to stereo, and mutes the original on that device while it is being read.
  2. A private aggregate device pairs the tap with your real output device.
  3. A single audio callback (an IOProc) runs the sound through a cascade of biquad filters, using the designs from the RBJ Audio EQ Cookbook, on its way to the speakers. It asks for the tap's input only, so a headset's microphone is not started.
  4. Parameter changes from the window reach the audio thread through a lock-free queue and are smoothed so that dragging a band does not click.

Your output device stays your output device, and the volume keys keep working. The aggregate device is private, so it does not show up for other apps.

What you give up

Being honest about the trade-offs:

  • macOS 14.2 or later. The API does not exist on older versions, so EQ does not run on them.
  • A permission. macOS guards audio capture behind the System Audio Recording permission, and asks the first time. Nothing is recorded or saved, and EQ makes no network connections. If you hear nothing, enable EQ under System Settings › Privacy & Security › Screen & System Audio Recording.
  • Unsigned by Apple. The app is not notarized, so macOS blocks the first launch until you choose Open Anyway. The source is public if you would rather build it yourself.
  • PCM audio only. If an output is passing encoded audio such as Dolby Digital through to a receiver, EQ cannot process its format. Switch passthrough off, or pick a PCM format for the device in Audio MIDI Setup.
  • Current output only. EQ equalizes what plays on your current output. Apps you send to another device play there untouched.
  • Intel is untested. The download is a universal build, but it is developed on Apple silicon and the Intel half has not been tested yet.

Quitting puts everything back

No driver or background service is installed. Quitting EQ (⌘Q) restores normal audio immediately, and uninstalling is quitting the app and deleting EQ.app. Closing the window alone leaves EQ running in the menu bar. Settings live in ~/Library/Application Support/eq/.

Built to be safe on the audio thread

The audio thread does not allocate, lock or panic into Core Audio. A stray NaN from any app becomes silence instead of sticking in the filters, filter state is kept out of the subnormal numbers that slow Intel processors down, and an output whose format is not 32-bit float is left alone. EQ is written in Rust, with egui for the interface and objc2 for Core Audio. The code is on GitHub under the GPL-3.0.

Frequently asked questions

Do I need BlackHole, Soundflower or another virtual audio driver?

No. EQ captures system audio with a Core Audio process tap, which is built into macOS 14.2 and later.

Why does macOS ask for permission to record audio?

Reading system audio is what lets the app equalize it, and macOS guards that behind the System Audio Recording permission. Nothing is recorded or saved.

Does EQ work on macOS versions older than 14.2?

No. The process tap API it relies on was added in macOS 14.2.

How do I uninstall EQ?

Turn off Open at Login if you enabled it, quit the app and delete EQ.app. No drivers or background services are installed.
